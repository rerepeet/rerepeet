# Security

## Keys

Never commit a provider key to this repository or paste one into an issue. Rerepeet holds a key in active app memory by default. If a user enables “remember key,” the desktop app uses Electron’s operating-system secure storage when it is available.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/rerepeet/rerepeet/security/advisories/new) for a suspected security issue. Include the app version, operating system, and a minimal reproduction without any credentials.

## Product boundary

Rerepeet does not provide hidden recording, evasion, unauthorized assistance, or provider-key bypasses. Recording requires visible, affirmative consent in the app.
